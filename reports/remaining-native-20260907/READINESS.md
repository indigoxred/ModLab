The standalone PapyrusUtil 4.8 DLL and the PapyrusUtil DLL bundled in this SexLab archive are byte-identical: SHA256 `69260a675186cf781a2105002505ab224fee12e84d004a3787670c9d6ce936be`. Either copy supplies the same DLL bytes in this exact pair. A follow-up comparison found 13 shared paths: the DLL and six source scripts match exactly, while six compiled `.pex` scripts differ. Matching source scripts do not prove the supplied compiled programs are equivalent; differing compiled bytes do not prove a functional conflict either. Their compiler/debug metadata or executable instructions have not been compared. The complete overlap therefore remains a review item, not a blanket incompatibility or compatibility claim. No file-order change was made. [Shared-file hashes](papyrus-shared-files.json) retain this distinction.

These are checks of selected native components, not a readiness verdict for all 64 archives. The existing live RaceMenu runtime rejection remains separately documented. Texture/body-family conflicts, animation frameworks, quests, external requirements and remaining helpers still need their applicable checks. A mod can pass its DLL declaration check and still fail to initialize or behave correctly.

The [Fuz Ro D'oh author page](https://www.nexusmods.com/skyrimspecialedition/mods/15109) independently lists 1.6.1170 and GOG 1.6.1179 support. It explains that its purpose is readable timing for unvoiced dialogue; missing that behavior is a functional problem even if a quest mod installs without an error. The [Ultimate Combat author page](https://www.nexusmods.com/skyrimspecialedition/mods/17196) lists Skyrim 1.5.97 / SKSE 2.0.17 and requests help with AE support. Neither page was treated as evidence that a verified 1.7.104 replacement exists. Both pages were checked during this pass.

Read-only extracted bytes are retained only in the local task's output directory under SHA256-based `.bin` filenames; project report copies and the package exclude them. They are test evidence, not files to copy into the game. No change to the delivered ModLab ZIP was needed: these results exercised its existing inspector.
